---

## 📋 Overview

The AETHERIC Admin Panel is a dedicated management interface built for store operators. It connects directly to Supabase and Firebase Auth infrastructure, giving admins real-time visibility into every order, customer, and revenue metric — with full control over store operations.

🏪 **Admins can:**
- 📦 View and manage all orders with status filtering (Pending, Paid, Shipped, Delivered)
- 📊 Track user growth trends with interactive charts
- 💰 Monitor total revenue, pending payments, and conversion rates
- 📈 Analyse sales trends, category revenue, top products, and peak order times
- 🕐 View live clock and personalized greeting based on time of day
- 🌗 Toggle between Dark and Light themes for comfortable viewing
- 📱 Access via fully responsive interface on any device

## 🖥️ Dashboard Sections

### 1. Dashboard View
- **6 Analytics Cards:** Total Users, Total Orders, Total Revenue, Pending Payments, Avg Order Value, Conversion Rate
- **User Growth Chart:** 7-day trend line with new user signups
- **Live Clock Widget:** Time-based greeting + real-time clock

### 2. Graphs & Analytics View
- **Sales Trend:** 7-day revenue line chart
- **Revenue by Category:** Pie chart breakdown
- **Top Selling Products:** Bar chart of bestsellers
- **Peak Order Times:** Hourly order distribution

### 3. Order Management View
- **Filterable Table:** All/Pending/Paid/Shipped/Delivered
- **Order Details:** Click to view full order information
- **Status Badges:** Color-coded for quick scanning

## 🛠️ Tech Stack

### Frontend
- **HTML5, CSS3, JavaScript** — vanilla, no frameworks
- **Chart.js 4.4** — interactive analytics charts
- **Font Awesome 6** — clean iconography
- **Google Fonts (Inter)** — modern typography
- **CSS Grid & Flexbox** — responsive layout

### Backend (Ready for Integration)
- **Node.js + Express** — protected REST API
- **Supabase** (PostgreSQL + Realtime) — orders, products, customers
- **Firebase Admin SDK** — token verification + role claims

---

## 🔐 Access Control

This panel is protected at two levels:

| Level | Protection |
|---|---|
| **Frontend** | Login form with email/password validation |
| **Backend** | Firebase custom claims — only `admin` role can access API |
